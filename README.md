# FitLog

FitLog is a modern workout management web application that helps users explore different exercises, create a daily workout plan, and save workouts for later. Users can view workout details and manage their selected exercises easily.

## Technologies Used

* Next.js
* React
* JavaScript
* Tailwind CSS
* DaisyUI
* React Toastify
* REST API

## Features

* Browse a collection of different workouts and exercises.
* View detailed information about each workout.
* Add exercises to Today's Plan.
* Save workouts for later.
* Remove workouts from Today's Plan or Saved list.
* View total exercises, duration, and calories in the plan.
* Sort workouts by calories, duration, and rating.
* Responsive design for different screen sizes.
* Loading state while workout data is being fetched.
* Toast notifications for user actions.

## API

Workout data is fetched from the FitLog API:

`https://api.abcz.workers.dev/api/fitlog`

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
